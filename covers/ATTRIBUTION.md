# Cover illustrations

Milo Winter, from *The Aesop for Children* (Rand McNally, 1919), which is in the public domain.
Scans from Project Gutenberg ebook 19994: https://www.gutenberg.org/ebooks/19994
Each file here is a square crop of one plate, made by `scripts/make-covers.mjs`.

The other six books use drawings made for this app (src/components/art/Banners.tsx).
